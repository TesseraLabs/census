окна. Зависит от `enumerable-domains` (контроли). Слой строго read-only: отчёт не изменяет
систему.

## 1. Обратное раскрытие

- [ ] 1.3 Раскрытие меры до объектов устройства через контроли и права.

## 2. Состояние объектов

- [ ] 2.1 Два независимых признака объекта: применён / состояние подтверждено чтением.
- [ ] 2.2 Чтение фактического состояния через существующие механизмы инспекции, без
      дублирования логики доменов.
- [ ] 2.3 Тест: применённый, но неподтверждённый объект отображается раздельно.
