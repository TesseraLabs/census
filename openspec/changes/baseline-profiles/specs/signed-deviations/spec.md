# signed-deviations Specification (delta: baseline-profiles)

## ADDED Requirements

### Requirement: Подписанное отклонение

Census ДОЛЖЕН (MUST) поддерживать подписанные отклонения от базлайна. Отклонение ДОЛЖНО
(MUST) содержать предмет (контроль, правило либо объект базлайна), обоснование, область
действия, срок и подпись. Отклонение без срока НЕ ДОЛЖНО (MUST NOT) приниматься.

#### Scenario: Действующее отклонение снимает требование
- **WHEN** отклонение применимо к устройству, подписано и не истекло
- **THEN** названное им требование не блокирует применение

#### Scenario: Отклонение без срока
- **WHEN** отклонение не содержит срока действия
- **THEN** оно отвергается

### Requirement: Отклонение только ослабляет

Отклонение НЕ ДОЛЖНО (MUST NOT) добавлять права, объекты или контроли и ДОЛЖНО (MUST)
лишь снимать перечисленное в базлайне. Отклонение, содержащее расширение, ДОЛЖНО (MUST)
отвергаться целиком.

#### Scenario: Попытка расширения через отклонение
- **WHEN** отклонение добавляет право, отсутствующее в базлайне
- **THEN** отклонение отвергается целиком, а не частично применяется

### Requirement: Область действия и истечение

Отклонение ДОЛЖНО (MUST) указывать область действия; при отсутствии явного указания
область ДОЛЖНА (MUST) считаться наиболее узкой. Отклонение, выданное для другого
устройства или группы, ДОЛЖНО (MUST) игнорироваться. По истечении срока требование ДОЛЖНО
(MUST) возвращаться в силу без действий оператора.

#### Scenario: Чужое отклонение
- **WHEN** отклонение выдано для другого устройства
- **THEN** оно не учитывается, требование остаётся в силе

#### Scenario: Истечение срока
- **WHEN** срок действующего отклонения истёк
- **THEN** требование вновь блокирует применение, отчёт называет истёкшее отклонение
