# provisioning-apply Specification (delta: effect-classes)

## ADDED Requirements

### Requirement: Гейт политики классов в конвейере apply

`census apply` ДОЛЖЕН (MUST) выполнять гейт политики классов эффектов до снятия снапшота
и до любых мутаций, наряду с существующими гейтами доверия к декларации и защиты от
lockout. Порядок гейтов ДОЛЖЕН (MUST) быть детерминированным, а отказ любого из них
ДОЛЖЕН (MUST) оставлять систему нетронутой.

#### Scenario: Нарушение политики при apply
- **WHEN** apply запущен с декларацией, нарушающей `max_effect_class`
- **THEN** apply отказывает до снапшота, мутаций нет, managed-реестр не изменён

#### Scenario: Совместная работа гейтов
- **WHEN** декларация одновременно не проходит проверку подписи и нарушает политику
  классов
- **THEN** apply отказывает, система не изменена, причина отказа определена
  детерминированным порядком гейтов
