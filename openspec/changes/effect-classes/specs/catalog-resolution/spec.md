# catalog-resolution Specification (delta: effect-classes)

## ADDED Requirements

### Requirement: Аннотация класса эффекта при резолве

Резолв ДОЛЖЕН (MUST) присваивать класс эффекта каждому разрешённому объекту и передавать
его дальше в план как данные. Резолв НЕ ДОЛЖЕН (MUST NOT) отказывать по классу
самостоятельно — решение принимает гейт политики; при отсутствии политики классы остаются
чисто информационными.

#### Scenario: Классы доступны плану
- **WHEN** резолв завершён
- **THEN** каждый разрешённый объект несёт вычисленный класс эффекта

#### Scenario: Резолв не решает за политику
- **WHEN** объект класса `escalation` разрешён, а политика в декларации отсутствует
- **THEN** резолв завершается успешно, класс присутствует в данных
