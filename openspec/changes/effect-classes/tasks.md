--all-targets --all-features` зелёные, ревью `master-code-reviewer`. Коммит/PR — вне

## 1. Шкала и вычисление класса

- [ ] 1.1 `src/effect.rs`: `enum EffectClass { Curated, Raw, Escalation }` с `Ord`
      (порядок = возрастание чувствительности), `Display`, serde. Отдельно —
      представление запрещённого `unbounded` для сообщений и скоупов, не присваиваемое
      объектам.
- [ ] 1.2 Функция классификации по типу объекта и признакам: каталожность, вид примитива,
      исполняемость файлового гранта, inline sudo.
- [ ] 1.3 Консервативное правило: недостоверный признак → более высокий класс. Тест на
      каждую ветку неопределённости.
- [ ] 1.4 Unit: таблица «объект → ожидаемый класс» по всем существующим типам объектов;
      тест, что порядок `Curated < Raw < Escalation` соблюдён.

## 2. Аннотация при резолве

- [ ] 2.1 Резолв присваивает класс каждому разрешённому объекту; класс едет в структуры

- [ ] 2.2 Резолв не отказывает по классу самостоятельно (тест: `escalation` без политики
