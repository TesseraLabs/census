# state-import Specification (delta: state-import)

## ADDED Requirements

### Requirement: Снятие фактического состояния без изменений

Census ДОЛЖЕН (MUST) предоставлять операцию снятия фактического состояния устройства в
допущенных доменах, которая НЕ ДОЛЖНА (MUST NOT) изменять систему. Операция ДОЛЖНА (MUST)
завершаться и при частично недоступных источниках фактов, отмечая недоступное в отчёте.

#### Scenario: Импорт не меняет систему
- **WHEN** выполнена операция импорта
- **THEN** состояние системы и managed-реестр не изменены

#### Scenario: Недоступный источник фактов
- **WHEN** часть фактов прочитать не удалось
- **THEN** операция завершается, недоступное перечислено в отчёте

### Requirement: Черновик декларации помечен и неприменим

Результат импорта ДОЛЖЕН (MUST) быть помечен как черновик и НЕ ДОЛЖЕН (MUST NOT)
приниматься к применению без прохождения обычной процедуры доверия. Отметка чернового
статуса НЕ ДОЛЖНА (MUST NOT) удаляться автоматически.

#### Scenario: Попытка применить черновик
- **WHEN** черновик подан на применение без подписи
- **THEN** применение отклоняется процедурой доверия

### Requirement: Консервативное разложение

Найденное состояние ДОЛЖНО (MUST) записываться как контроль, только если соответствует ему
полностью. При частичном соответствии ДОЛЖНЫ (MUST) записываться сырые объекты с пометкой о
похожем контроле и характере отличий.

#### Scenario: Полное соответствие контролю
- **WHEN** найденные объекты полностью соответствуют контролю каталога
- **THEN** черновик содержит объявление контроля, а не перечень объектов

#### Scenario: Частичное соответствие
- **WHEN** найденные объекты соответствуют контролю не полностью
- **THEN** черновик содержит сырые объекты и пометку о похожем контроле с отличиями

### Requirement: Отчёт разложения

Операция ДОЛЖНА (MUST) выводить отчёт: что распознано как контроли, что записано сырыми
объектами, что не разложилось на каталог и какие области остались вне допущенных доменов.
Перечень нераспознанного НЕ ДОЛЖЕН (MUST NOT) опускаться при пустом результате остальных
разделов.

#### Scenario: Нераспознанные объекты
- **WHEN** часть найденного не сопоставляется с каталогом
- **THEN** отчёт содержит их перечень отдельным разделом

#### Scenario: Области вне доменов
- **WHEN** на устройстве присутствует состояние вне допущенных доменов
- **THEN** отчёт называет эти области как не вошедшие в черновик
