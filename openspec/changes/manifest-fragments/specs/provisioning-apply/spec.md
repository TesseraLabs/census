# provisioning-apply Specification (delta: manifest-fragments)

## ADDED Requirements

### Requirement: Источник объекта в managed-реестре

Managed-реестр ДОЛЖЕН (MUST) записывать источник каждого управляемого объекта и сохранять
его между запусками. Объект без записанного источника ДОЛЖЕН (MUST) трактоваться как
принадлежащий операторской декларации (совместимость с реестрами, созданными до этого
изменения).

#### Scenario: Реестр, созданный ранее
- **WHEN** apply работает с managed-реестром без поля источника
- **THEN** объекты трактуются как операторские, миграция происходит без потери владения
