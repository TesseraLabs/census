## Why

Релиз census сейчас публикует только «голый» статический musl-бинарь на GitHub
Release. Операторам на Debian/Ubuntu/Astra и RHEL-семействе приходится вручную
раскладывать его и деревья данных (`/usr/share/census/permissions`,
`/usr/share/census/frameworks`) по FHS-путям, которые бинарь ждёт. Нативные
пакеты `.deb` и `.rpm` устраняют ручную раскладку и дают штатную установку через
пакетный менеджер.

## What Changes

- Релизный пайплайн (`release.yml`, триггер `v*`-тег) дополнительно собирает и
  публикует `.deb` и `.rpm` рядом с существующим musl-бинарём, каждый со своим
  `.sha256`.
- Появляется единый декларативный конфиг сборки пакетов `packaging/nfpm.yaml`
  (инструмент — nfpm: один файл → оба формата, без `rpmbuild`/`dpkg-dev`-окружения
  в CI).
- Пакеты раскладывают файлы строго по захардкоженным в бинаре FHS-путям: бинарь в
  `/usr/bin`, каталог permissions и frameworks в `/usr/share/census/`, пустые
  override-директории в `/etc/census/`, доки/примеры в `/usr/share/doc/census/`.
- Пакеты **не объявляют рантайм-зависимостей** (бинарь — статический musl).
- Триггер не меняется: пакеты собираются только на `v*`-теге; PR и push в `main`
  не затрагиваются.

## Capabilities

### New Capabilities
- `packaging`: сборка и публикация нативных дистрибутивных пакетов (`.deb`,
  `.rpm`) из релизного musl-бинаря — раскладка файлов по FHS, метаданные пакета,
  публикация ассетов Release с контрольными суммами.

## Impact

- **CI:** `.github/workflows/release.yml` — добавляются шаги установки nfpm,
  сборки пакетов, контрольных сумм и расширяется список публикуемых ассетов.
- **Новый файл:** `packaging/nfpm.yaml`.
- **Зависимости рантайма:** нет (статический musl-бинарь, пакеты без Depends).
- **Инструменты CI:** добавляется pinned-бинарь nfpm (по образцу установки `taplo`
  в `ci.yml`).
- **Код продукта (Rust):** не затрагивается. FHS-пути в пакете обязаны совпадать
  с уже захардкоженными константами (`default_catalog_roots` в `src/cli/mod.rs`,
  корни frameworks в `src/framework.rs`, l10n-дерево в `src/l10n.rs`).
- **Покрытие:** только `x86_64` (как текущий релизный таргет); arm64 вне объёма.
