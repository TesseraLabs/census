## ADDED Requirements

### Requirement: Сборка нативных пакетов на релизном теге
Релизный пайплайн ДОЛЖЕН (MUST) на пуш `v*`-тега собирать пакет `.deb` и пакет
`.rpm` из того же стрипнутого статического musl-бинаря, что публикуется как
самостоятельный ассет. Сборка пакетов НЕ ДОЛЖНА (MUST NOT) запускаться на pull
request или push в `main`.

#### Scenario: Тег запускает сборку обоих форматов
- **WHEN** в репозиторий пушится тег вида `vX.Y.Z`
- **THEN** пайплайн производит ровно один файл `.deb` и ровно один файл `.rpm`,
  оба собранные из уже стрипнутого musl-бинаря этого же прогона

#### Scenario: PR не собирает пакеты
- **WHEN** открыт pull request или выполнен push в `main`
- **THEN** шаги сборки `.deb`/`.rpm` не выполняются

### Requirement: Раскладка файлов по FHS совпадает с путями бинаря
Пакеты ДОЛЖНЫ (MUST) раскладывать файлы строго по тем FHS-путям, которые бинарь
census ищет в рантайме: бинарь в `/usr/bin/census` (режим 0755), дерево permissions
(включая поддерево `l10n/`) в `/usr/share/census/permissions/`, дерево frameworks в
`/usr/share/census/frameworks/`, файлы `README.md`/`CHANGELOG.md`/`LICENSE` и дерево
`examples/` в `/usr/share/doc/census/`. Пакеты НЕ ДОЛЖНЫ (MUST NOT) устанавливать
файл декларации в `/etc/census/declaration.toml` — это политика оператора.

#### Scenario: Установленный бинарь находит каталог без флагов
- **WHEN** пакет установлен на целевой хост и запущен `census plan` без
  переопределяющих путь флагов
- **THEN** census разрешает каталог permissions из
  `/usr/share/census/permissions` и frameworks из `/usr/share/census/frameworks`

#### Scenario: Декларация не входит в пакет
- **WHEN** инспектируется содержимое `.deb` или `.rpm`
- **THEN** файл `/etc/census/declaration.toml` в пакете отсутствует

### Requirement: Пустые override-директории
Пакеты ДОЛЖНЫ (MUST) создавать пустые drop-in директории
`/etc/census/permissions.d/` и `/etc/census/frameworks.d/` (режим 0755), чтобы
оператор сразу видел штатное место для оверрайдов.

#### Scenario: Override-директории присутствуют и пусты
- **WHEN** пакет установлен
- **THEN** существуют каталоги `/etc/census/permissions.d/` и
  `/etc/census/frameworks.d/`, и оба пусты

### Requirement: Метаданные пакета без рантайм-зависимостей
Пакеты ДОЛЖНЫ (MUST) объявлять версию, совпадающую с `[package] version` в
`Cargo.toml` (выведенную из имени тега со снятым префиксом `v`), архитектуру
`amd64` (deb) / `x86_64` (rpm), лицензию `AGPL-3.0-only`, вендора `TesseraLabs` и
homepage репозитория. Пакеты НЕ ДОЛЖНЫ (MUST NOT) объявлять рантайм-зависимости
(Depends/Requires), так как бинарь статически слинкован с musl.

#### Scenario: Версия пакета равна версии крейта
- **WHEN** собран пакет для тега `vX.Y.Z`
- **THEN** объявленная версия пакета равна `X.Y.Z` и равна `[package] version` в
  `Cargo.toml`

#### Scenario: Нет объявленных зависимостей
- **WHEN** инспектируются метаданные `.deb` (`Depends`) и `.rpm` (`Requires`)
- **THEN** список рантайм-зависимостей пуст

### Requirement: Публикация пакетов как ассетов Release
Релизный пайплайн ДОЛЖЕН (MUST) публиковать собранные `.deb` и `.rpm` как ассеты
GitHub Release этого тега, каждый сопровождённый файлом контрольной суммы
`.sha256`, рядом с уже публикуемым musl-бинарём.

#### Scenario: Ассеты с контрольными суммами приложены к Release
- **WHEN** релизный прогон для тега завершился успешно
- **THEN** к Release приложены файл `.deb`, файл `.rpm` и по одному `.sha256` на
  каждый, наряду с musl-бинарём и его `.sha256`
