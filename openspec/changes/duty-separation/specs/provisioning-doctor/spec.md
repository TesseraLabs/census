# provisioning-doctor Specification (delta: duty-separation)

## ADDED Requirements

### Requirement: Находки разделения обязанностей

`census doctor` ДОЛЖЕН (MUST) сообщать о нарушениях правил несовместимости, не блокируя
работу, с указанием роли, конфликтующих прав, общего примитива и затронутой меры. Находки
ДОЛЖНЫ (MUST) иметь устойчивые идентификаторы для использования в мониторинге и тестах.

#### Scenario: Обнаружение без блокировки
- **WHEN** doctor запущен на системе с нарушением правила несовместимости
- **THEN** нарушение сообщено как находка, команда не изменяет систему

#### Scenario: Разрешённое исключением нарушение
- **WHEN** для нарушения действует подписанное исключение
- **THEN** находка сообщается отдельным уровнем как разрешённая, с указанием срока
