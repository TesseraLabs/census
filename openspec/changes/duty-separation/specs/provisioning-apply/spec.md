# provisioning-apply Specification (delta: duty-separation)

## ADDED Requirements

### Requirement: Гейт разделения обязанностей

`census apply` ДОЛЖЕН (MUST) отказывать при наличии неразрешённого нарушения правил
несовместимости, выполняя проверку до снятия снапшота и до любых мутаций, наряду с
существующими гейтами. Отказ ДОЛЖЕН (MUST) перечислять все нарушения, а не первое
обнаруженное.

#### Scenario: Нарушение блокирует применение
- **WHEN** эффективная декларация содержит неразрешённое нарушение
- **THEN** apply отказывает до снапшота, система не изменена, перечислены все нарушения
