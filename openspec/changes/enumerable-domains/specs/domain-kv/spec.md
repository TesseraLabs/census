# domain-kv Specification (delta: enumerable-domains)

## ADDED Requirements

### Requirement: Движок типизированных ключ-значение целей

Census ДОЛЖЕН (MUST) поддерживать единый движок целей вида ключ-значение, поведение
которых задаётся словарями-данными, а не кодом. Словарь цели ДОЛЖЕН (MUST) определять
множество допустимых ключей, тип и допустимые значения каждого ключа, механизм применения,
класс эффекта и привязку к мерам. Ключ, отсутствующий в словаре цели, ДОЛЖЕН (MUST)
отвергаться.

#### Scenario: Добавление цели без изменения кода
- **WHEN** в каталог добавлен новый словарь цели
- **THEN** цель становится доступной для объявления без пересборки Census

#### Scenario: Ключ вне словаря
- **WHEN** декларация объявляет ключ, отсутствующий в словаре цели
- **THEN** разбор отвергает объявление

#### Scenario: Значение неверного типа
- **WHEN** значение ключа не соответствует типу из словаря
- **THEN** разбор отвергает объявление с указанием ключа и ожидаемого типа

### Requirement: Различение объявленного, записанного и действующего

Отчёт применения ДОЛЖЕН (MUST) различать три состояния ключа: объявлено, записано в
целевой файл, действует в системе. Ключ, записанный, но не вступивший в силу без
перезагрузки, НЕ ДОЛЖЕН (MUST NOT) представляться как действующий.

#### Scenario: Требуется перезагрузка
- **WHEN** значение записано в целевой файл, но не применено к работающей системе
- **THEN** отчёт показывает записанное и не показывает действующим, называя причину
