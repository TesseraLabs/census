# domain-modules Specification (delta: enumerable-domains)

## ADDED Requirements

### Requirement: Запрет загрузки модулей ядра

Census ДОЛЖЕН (MUST) материализовать запрет загрузки перечисленных модулей ядра через
маркированный файл конфигурации подсистемы модулей, включая как запись чёрного списка, так
и подмену команды загрузки. Снятие объекта ДОЛЖНО (MUST) удалять соответствующие записи из
управляемого файла, не затрагивая записи, созданные вне Census.

#### Scenario: Запрет модуля
- **WHEN** объявлен запрет модуля, отсутствующий в системе
- **THEN** план содержит добавление записей, применение создаёт их в управляемом файле

#### Scenario: Чужие записи не затрагиваются
- **WHEN** в конфигурации подсистемы модулей есть записи, созданные не Census
- **THEN** применение и снятие их не изменяют

### Requirement: Выгрузка загруженного модуля

При применении запрета Census ДОЛЖЕН (MUST) попытаться выгрузить модуль, если он загружен.
Невозможность выгрузки (модуль занят) НЕ ДОЛЖНА (MUST NOT) считаться отказом применения и
ДОЛЖНА (MUST) отражаться в отчёте как требующая перезагрузки.

#### Scenario: Модуль занят
- **WHEN** запрещаемый модуль загружен и используется
- **THEN** запись создана, выгрузка не выполнена, отчёт указывает на необходимость
  перезагрузки
