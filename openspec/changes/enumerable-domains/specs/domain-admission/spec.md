# domain-admission Specification (delta: enumerable-domains)

## ADDED Requirements

### Requirement: Критерий допустимости домена

Домен ДОЛЖЕН (MUST) допускаться в модель Census, только если выполнены все пять условий:
объекты домена перечислимы до применения; объект несёт маркер принадлежности, отличающий
управляемое от чужого; обратная операция определена так же строго, как прямая; объект
сопоставим с мерами внешних наборов требований; каждому типу объекта присвоен класс
эффекта. Домен, чьи объекты имеют неограниченный (unbounded) эффект, НЕ ДОЛЖЕН (MUST NOT)
допускаться.

#### Scenario: Домен с неограниченным эффектом
- **WHEN** предлагается домен, объектом которого является произвольная строка конфигурации
  службы
- **THEN** домен не допускается как несущий неограниченный эффект

#### Scenario: Ограниченность определяется эффектом, а не объёмом
- **WHEN** объектом домена является файл целиком, но множество его эффектов ограничено и
  описано
- **THEN** признак объёма не является основанием для отказа; решают пять условий

### Requirement: Обязательства допущенного домена

Каждый допущенный домен ДОЛЖЕН (MUST) поддерживать перечисление текущего состояния,
вычисление разницы с объявленным, применение, снапшот затрагиваемого состояния и снятие
объекта. Домен, не поддерживающий снятие, НЕ ДОЛЖЕН (MUST NOT) допускаться.

#### Scenario: Снятие объекта домена
- **WHEN** объект домена исчез из эффективной декларации
- **THEN** домен возвращает затронутое состояние к состоянию до управления им
