# domain-trust-anchors Specification (delta: enumerable-domains)

## ADDED Requirements

### Requirement: Типизированные наборы доверенных ключей

Census ДОЛЖЕН (MUST) управлять наборами публичных ключей, сгруппированными по назначению.
Объекты этого домена ДОЛЖНЫ (MUST) иметь класс эффекта `escalation`. Материал ключа ДОЛЖЕН
(MUST) проверяться на соответствие объявленному формату до записи.

#### Scenario: Добавление доверенного ключа
- **WHEN** объявлен набор ключей заданного назначения
- **THEN** объекты набора получают класс `escalation` и подчиняются политике классов

#### Scenario: Некорректный материал ключа
- **WHEN** объявленный ключ не соответствует формату назначения
- **THEN** объявление отвергается до записи

### Requirement: Бутстрап-якорь вне управления

Пинённый корень доверия самого Census НЕ ДОЛЖЕН (MUST NOT) быть управляемым объектом этого
домена. Попытка объявить его ДОЛЖНА (MUST) отвергаться.

#### Scenario: Попытка управлять собственным корнем
- **WHEN** декларация объявляет пинённый корень доверия Census объектом домена
- **THEN** объявление отвергается
