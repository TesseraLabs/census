# domain-units Specification (delta: enumerable-domains)

## ADDED Requirements

### Requirement: Состояние юнита как объект

Census ДОЛЖЕН (MUST) управлять состоянием юнитов системы инициализации в трёх значениях:
включён, выключен, замаскирован. Содержимое юнитов и их дополнений НЕ ДОЛЖНО (MUST NOT)
входить в домен. Текущее состояние ДОЛЖНО (MUST) читаться из системы, а не предполагаться.

#### Scenario: Маскирование службы
- **WHEN** объявлено состояние «замаскирован» для запущенной службы
- **THEN** план показывает изменение состояния, применение приводит юнит в объявленное
  состояние

#### Scenario: Содержимое юнита вне домена
- **WHEN** декларация пытается объявить содержимое юнита
- **THEN** разбор отвергает объявление
