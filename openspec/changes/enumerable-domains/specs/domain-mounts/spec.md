# domain-mounts Specification (delta: enumerable-domains)

## ADDED Requirements

### Requirement: Опции монтирования для перечисленных точек

Census ДОЛЖЕН (MUST) управлять опциями монтирования явно перечисленных точек, принимая
только опции из белого списка, включая опции связывания каталога с самим собой. Точки, не
перечисленные в декларации, НЕ ДОЛЖНЫ (MUST NOT) затрагиваться.

#### Scenario: Ужесточение опций точки
- **WHEN** для перечисленной точки объявлены ограничивающие опции
- **THEN** план показывает изменение, применение приводит точку к объявленным опциям

#### Scenario: Создание точки связывания
- **WHEN** объявлена точка, связывающая каталог с самим собой, отсутствующая в системе
- **THEN** применение создаёт её и делает сохраняющейся между перезагрузками

#### Scenario: Опция вне белого списка
- **WHEN** объявлена опция монтирования, отсутствующая в белом списке
- **THEN** объявление отвергается

### Requirement: Единственность владельца точки

Точка монтирования, объявленная в этом домене, НЕ ДОЛЖНА (MUST NOT) быть одновременно
объявлена как объект домена юнитов. Двойное объявление ДОЛЖНО (MUST) приводить к отказу.

#### Scenario: Точка объявлена дважды
- **WHEN** одна точка объявлена и как объект монтирования, и как юнит
- **THEN** plan и apply отказывают с указанием обоих объявлений
